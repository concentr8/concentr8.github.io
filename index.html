Concentr8 is a study and focus app for students with ADHD: pick one task, start it, and keep going with a timer, music, a body-double room and a block list for distracting apps.

Concentr8 runs on your laptop. Open this page there, or use the web app right here.

Install in three minutes

Concentr8 is not signed by Apple or Microsoft yet, so your computer asks once whether you trust it. Here is exactly what to click.

  1. Pick the right fileApple menu, About This Mac. "Chip: Apple M..." means Apple chip, "Processor: Intel" means Intel.
  2. Drag it into ApplicationsOpen the downloaded .dmg file and drag Concentr8 onto the Applications folder.
  3. Run this once in TerminalWithout it, macOS says the app "is damaged". It only removes the download mark from Concentr8.
    xattr -cr /Applications/Concentr8.app

    Terminal: press Cmd + Space, type Terminal, press Enter, paste, press Enter.

  4. Open Concentr8When it asks to control Chrome, Safari or System Events, click OK. That is how the block list sees distracting tabs. For Firefox also turn on Concentr8 in System Settings, Privacy & Security, Accessibility.
  1. Open the installerOpen Concentr8-x64.exe from your Downloads folder.
  2. Click "More info", then "Run anyway"Windows shows "Windows protected your PC" for new apps that are not signed yet. The "Run anyway" button appears only after you click "More info".
  3. DoneIt installs for your account only (no admin password) and opens by itself. Later you find it in the Start menu and on the desktop. To remove it: Settings, Apps, Concentr8, Uninstall.
  1. Once: install FUSE 2AppImages need it. Without it you see "AppImages require FUSE to run". Ubuntu 24.04 or newer, Debian 13:
    sudo apt install libfuse2t64

    Ubuntu 22.04: sudo apt install libfuse2. Fedora: sudo dnf install fuse fuse-libs. Do not install the package called just fuse on Ubuntu, it can break the system.

  2. Make it runnable and start itAfter downloading Concentr8-x86_64.AppImage:
    chmod +x ~/Downloads/Concentr8-x86_64.AppImage && ~/Downloads/Concentr8-x86_64.AppImage
    It stops with a "sandbox" error

    Some systems (for example Ubuntu 24.04) block the sandbox of Electron apps. Start it with --no-sandbox at the end.

    No admin rights for step 1

    Start it with --appimage-extract-and-run at the end. It needs no FUSE, only starts a bit slower.

  3. For the block list: xdotool and X11Concentr8 reads window titles with xdotool. It does not work in a Wayland session; pick "Ubuntu on Xorg" on the login screen.
    sudo apt install xdotool

What works where

Your tasks, timer and settings stay on your computer. The app shows the web app in a window and adds the block list.

Mac

Everything, including blocking websites by their address and sending you back to the last work tab.

Windows

Early version. The block list sees app names and window titles, not web addresses, and closes a blocked tab.

Linux

Early version. Same as Windows, and the block list needs xdotool and an X11 session.
